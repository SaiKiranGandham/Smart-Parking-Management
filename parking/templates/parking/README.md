# Smart Parking Management & Demand Analytics Platform

## Project Overview
A Django-based web application to manage parking slots, vehicle entry and exit, reservations, parking history, and revenue analytics.

## Technologies Used
- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap
- JavaScript
- Chart.js

## Features
- Parking slot management
- Vehicle entry and exit
- Slot availability tracking
- Parking reservations
- Parking history with search and filters
- Automatic parking fee calculation
- Revenue analytics
- Daily revenue chart
- Parking slot usage chart
- Django admin panel

## Installation

1. Clone the repository.
2. Install dependencies:
   `pip install django`
3. Run migrations:
   `python manage.py migrate`
4. Start the server:
   `python manage.py runserver`
